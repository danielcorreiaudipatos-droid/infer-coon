# 🎮 OnGame Mobile App

Play games, earn real money. Available on iOS and Android.

## Features

### 🎮 Three Amazing Games

**ONZAP** - Jumping Game
- Jump to earn R$ 0.10 - R$ 2.50 per game
- Up to 10x multiplier
- Real-time leaderboard

**ONLOVE** - Matching Game
- Swipe to find matches
- Earn R$ 0.05 - R$ 5.00 per match
- Reaction multipliers (Love 2x, Like 1x, Maybe 0.5x)

**ONMAIL** - Tower Defense
- Build towers and defend
- 3 difficulty levels
- Earn R$ 0.50 - R$ 200.00 per game

- Withdraw directly to your bank account or PIX

- Instant rewards
- No hidden fees

### 🛍️ Cosmetics Shop

- Customize your character
- Unlock skins, effects, themes
- Prices from R$ 1.99 - R$ 9.99

### 🏆 Leaderboards

- Compete globally
- Real-time rankings
- Daily and all-time stats
- Win bonuses!
