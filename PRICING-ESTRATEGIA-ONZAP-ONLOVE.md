## 💳 PAYMENT & BILLING SYSTEM

### Como Funciona o Billing

```
FLUXO 1: Assinatura (Recurring)
┌─────────────────────────────────────┐
│ 1. User selects plan (e.g., R$ 59)  │
│ 2. Payment method (card, PIX)       │
│ 3. Charge via Stripe/Assas          │
│ 4. User activated (auto)            │
│ 5. Recurring: Every 30 days         │
│ 6. Failed payment: 3 retry attempts │
│ 7. After 3 fails: Downgrade to free │
└─────────────────────────────────────┘

FLUXO 2: Add-ons (One-time)
┌─────────────────────────────────────┐
│ 1. Extra contacts: +R$ 9/1k         │
│ 2. Extra broadcasts: +R$ 19/10      │
│ 3. Extra API calls: +R$ 99/month    │
│ 4. Charge immediately               │
│ 5. Recurring billing for extras     │
└─────────────────────────────────────┘

FLUXO 3: Revenue Share (Ads/Campaigns)
┌─────────────────────────────────────┐
│ USER SPENDS: R$ 20 on Google ads    │
│                                     │
│ FLOW:                               │
│ 1. User clicks "Create ad"          │
│ 2. Inputs budget: R$ 20             │
│ 3. System processes ad creation     │
│ 4. OUR CUT: 20% = R$ 4             │
│ 5. GOOGLE/PLATFORM: 80% = R$ 16    │
│ 6. Charge user: R$ 20 (total)       │
│ 7. Send to Google: R$ 16            │
│ 8. Keep: R$ 4 (20% margin)          │
│                                     │
│ MARGIN: 20% (can adjust to 15-30%)  │
└─────────────────────────────────────┘
```
