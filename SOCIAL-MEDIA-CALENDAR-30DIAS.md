## 🎬 HOW TO POST

### LinkedIn
```
1. Escrever no editor do LinkedIn
2. Adicionar imagem (1200x627px ideal)
3. Agendador: Buffer ou Later
4. Melhor hora: 8am-10am, 12pm, 6pm-8pm (terça-quinta)
5. Publicar
```

### Instagram
```
1. Criar conteúdo no Canva (dimensões: 1080x1350 posts, 1080x1920 stories)
2. Agendar com Later ou Buffer
3. Melhores horas: 11am-1pm, 7pm-9pm
4. Usar hashtags relevantes (15-20)
5. Publicar
```

### TikTok
```
1. Gravar video (9:16 vertical)
2. Edit com CapCut (trending sounds)
3. Adicionar text overlays
4. Adicionar caption + hashtags
5. Upload para TikTok (NÃO agendar, postar direto)
6. Postar: 8am, 12pm, 6pm (horários que público está online)
```
