## 🔧 SE ALGO DER ERRADO

### Erro: "Vercel command not found"
```bash
npm install -g vercel
vercel --version
```

### Erro: "Deploy failed"
```bash
# Limpar cache
rm -rf .next
rm -rf node_modules
npm install
npm run build

# Tentar novamente
vercel --prod --name ongame-staging
```

### Erro: "Not logged in"
```bash
vercel logout
vercel login
# Siga instruções
```

### Jogo não carrega
```
- Abrir DevTools (F12)
- Ver console por erros
- Refreshar página (F5)
- Limpar cookies
```
