# 📥 IMPORTAR DADOS ANTIGOS {#import}

## Se você vinha de outra plataforma

### Passo 1: Exportar de Jetimob/Imobisoft/SICADI

#### Jetimob
```
1. Acesse Jetimob
2. Clique "Relatórios"
3. Selecione "Clientes" ou "Imóveis"
4. Clique "Exportar para Excel"
5. Salve como CSV (File > Save As > CSV)
6. Feche e vem para cá
```

#### Imobisoft
```
1. Acesse Imobisoft
2. Clique "Admin" > "Relatórios"
3. Selecione "Leads" ou "Propriedades"
4. Clique "Exportar CSV"
5. Salve
6. Feche e vem para cá
```

#### SICADI
```
1. Acesse SICADI
2. Clique "Gerenciar" > "Relatórios"
3. Selecione "Clientes" ou "Imóveis"
4. Clique "Baixar CSV"
5. Salve
6. Feche e vem para cá
```

### Passo 2: Importar em on.imob

```
1. Clique "Importar Dados" (big button no dashboard)
2. Selecione origem: Jetimob / Imobisoft / SICADI
3. Selecione tipo: Leads (contatos) ou Imóveis (propriedades)
4. Clique "Selecionar Arquivo"
5. Escolha o CSV que baixou
6. Clique "Preview"
7. Sistema mostra:
   - Total de registros
   - Quantos podem importar (sem erro)
   - Quais têm dados faltando
   - Exemplo dos primeiros 5

8. Se tudo OK: Clique "Importar"
9. Aguarde (1-5 minutos, depende da quantidade)
10. Vê mensagem "✓ XXX registros importados!"

Pronto! Todos seus dados estão em on.imob.
```

### O que pode dar errado?

```
❌ "Arquivo inválido"
   → Certifique-se: é CSV (não Excel)?
   → Abra em Notepad e confira o formato
   → Salve novamente como CSV em UTF-8

❌ "5 registros com dados faltando"
   → Isso é normal! Significa alguns campos em branco
   → Você pode editar depois (não é urgente)
   → Clique "Ver Dados com Erro" para corrigir

✅ "Importação OK, mas faltam dados"
   → Você tem 30 dias para completar
   → Clique no registro e complete manualmente
```

# 👤 CADASTRAR LEAD (Contato) {#cadastro-lead}

## O que é um Lead?
Um lead é um **contato de cliente** (prospect que quer comprar, alugar, etc).

## Como Cadastrar Manualmente

### Método 1: Via Dashboard

```
PASSO 1: Novo Lead
└─ Clique "Novo Lead" (botão vermelho)

PASSO 2: Informações Básicas
├─ Nome: João Silva (obrigatório)
├─ Telefone: 11999999999
├─ Email: joao@email.com
└─ Cidade: São Paulo

PASSO 3: Interesse
├─ Tipo de Imóvel: Apto / Casa / Comercial / Terreno
├─ Operação: Compra / Aluguel / Venda
├─ Preço (orçamento): R$ 500.000 - R$ 1.000.000 (opcional)
└─ Quartos desejados: 2, 3, 4?

PASSO 4: Notas
├─ Campo "Notas": "Cliente visitou 3 imóveis, muito interessado"
├─ Pode adicionar múltiplas notas
└─ Sistema ordena por mais recente

PASSO 5: Status
├─ Prospect: Novo, ainda explorando
├─ Negociando: Já viu algo que gostou
├─ Vendido: Fechou negócio!
└─ Descartado: Não está mais interessado

PASSO 6: Salvar
└─ Clique azul "Salvar Lead"

Resultado: Lead aparece no CRM, com histórico completo.
```

### Método 2: Via WhatsApp (Automático)

```
ATALHO: Cliente envia mensagem no WhatsApp
├─ on.imob recebe automaticamente
├─ IA cria lead + adiciona notas
├─ Você vê na sequência no CRM
└─ Histórico completo da conversa

Detalhes:
├─ Número: Salvo
├─ Mensagem: Em "Notas"
├─ Data: Automática
├─ Status: "Prospect" (por padrão)
└─ Pronto para ação!

# 🏠 CADASTRAR IMÓVEL {#cadastro-imovel}

Um imóvel é uma **propriedade** que você quer vender ou alugar (apto, casa, terreno, etc).

### Passo 1: Iniciar Cadastro

```
Clique "Novo Imóvel" (botão vermelho, dashboard)

### Passo 2: Dados Básicos (obrigatórios)

```
TÍTULO (Obrigatório)
├─ Exemplo: "Apto 2 quartos em Pinheiros"
├─ Exemplo: "Casa nova com piscina, Zona Oeste"
└─ Máximo 150 caracteres

ENDEREÇO (Obrigatório)
├─ Rua + número: "Rua das Flores, 123"
├─ Bairro: "Pinheiros"
├─ Cidade: "São Paulo"
├─ CEP: "01234-567"
└─ Sistema busca coordenadas automaticamente

TIPO (Obrigatório)
├─ Apartamento
├─ Casa
├─ Comercial
├─ Terreno
└─ Outros
```

### Passo 3: Características (Melhor com tudo preenchido)

```
DORMITÓRIOS
├─ Números: 1, 2, 3, 4, 5+
└─ Clique o número

BANHEIROS
├─ Números: 1, 2, 3, 4+
└─ Clique o número

ÁREA TOTAL (m²)
├─ Exemplo: 100.5
└─ Importante para avaliação

ÁREA ÚTIL (m²) [Opcional]
├─ Diferente da área total (área sem garagem, etc)
└─ Deixe branco se não souber

PREÇO (Opcional)
├─ Exemplo: 500000
├─ Sem pontuação (escreva 500000, não 500.000)
├─ Pode atualizar depois
└─ Sistema usa isso + outros para comparar

### Passo 4: Descrição Detalhada

```
DESCRIÇÃO (Opcional, mas MUITO recomendado)

├─ Máximo 1.000 caracteres
└─ Clientes leem aqui, seja convincente!

DESTAQUES
├─ ✓ Ar condicionado
├─ ✓ Churrasqueira
├─ ✓ Piscina
├─ ✓ Elevador
├─ ✓ Garagem
└─ Marca os que se aplicam

ADICIONAR FOTOS

# 💰 GERAR AVALIAÇÃO CIENTÍFICA {#avaliacao}

## O que é a Avaliação Científica?

```
É um DOCUMENTO que PROVA o valor real do imóvel.

Usa:
├─ Regressão estatística (matemática)
├─ Análise de market data (preços reais)
├─ Comparação de imóveis similares
└─ NBR 14.653 (norma brasileira de avaliação)

Resultado:
├─ Valor mínimo (com 80% de confiança)
├─ Valor máximo (com 80% de confiança)
├─ Gráficos e tabelas
└─ PDF assinado digitalmente
```

## Como Funciona

### Passo 1: Sistema Coleta Dados

```
Quando você insere um imóvel:
├─ Tipo: Apto / Casa / Comercial
├─ Localização: Endereço exato
├─ Características: Quartos, banheiros, área
├─ Preço: Se você colocou
└─ on.imob busca imóveis SIMILARES (80 imóveis de referência)
```

### Passo 2: IA Calcula Regressão

```
A IA faz contas:
├─ Quanto cada m² custa na região?
├─ Quanto custa ter 1 quarto a mais?
├─ Quanto custa estar perto do metrô?
├─ Quanto custa ter piscina?
└─ Soma tudo = Valor do seu imóvel
```

### Passo 3: Gera Documento

```
Resultado é um PDF com:
├─ RESUMO: Valor mínimo → Máximo
├─ DETALHES: Como foi calculado
├─ COMPARAÇÃO: 5 imóveis similares
├─ GRÁFICOS: Visual fácil de entender
├─ TABELA: Fatores usados
└─ DATA: Quando foi gerado

Totalmente científico. Você pode mostrar para cliente.
```

### Passo 4: Usar a Avaliação

```
COMPARTILHAR COM CLIENTE
├─ Clique "Enviar Avaliação"
├─ Selecione: Email / WhatsApp / Download
├─ Cliente recebe PDF
└─ Confia no valor (é científico, não palpite)

USAR NO ANÚNCIO
├─ Compartilhe o link do imóvel
├─ Inclua na descrição: "Avaliação científica disponível"
└─ Cliente vê que você é sério

PUBLICAR NO VIVAREAL
├─ Avaliação fica junto com o anúncio
├─ Cliente vê: "Este imóvel foi avaliado cientificamente"
└─ Aumenta confiabilidade (mais vendas)
```

├─ Sistema redireciona

```
PASSO 1: Abrir Imóvel

PASSO 2: Publicar
├─ Botão "Publicar no VivaReal"
├─ Selecione: "À venda" / "Aluguel" / "Aluga-se apto mobiliado"

```

Se vender o imóvel:

├─ Sistema remove automaticamente

# 💬 USAR WHATSAPP IA {#whatsapp}

## O que é WhatsApp IA?

```
É um ASSISTENTE AUTOMÁTICO que responde clientes no WhatsApp.

Funciona assim:
├─ Cliente envia mensagem
├─ IA lê e entende
├─ IA responde com sugestão
├─ Você aprova ou edita
└─ Envia para cliente

Resultado: Atender 100 clientes sozinho (quase).
```

## Como Funciona

### Passo 1: Primeiro Contato

```
Cliente envia no WhatsApp:
"Olá, procuro apto 2 quartos em Pinheiros"

on.imob recebe automaticamente e:
├─ Cria lead "Cliente novo"
├─ Adiciona mensagem nas notas
├─ IA gera resposta sugerida
└─ Você vê tudo no CRM
```

### Passo 2: Revisar Resposta

```
Na tela, você vê:
├─ Mensagem do cliente
├─ Resposta sugerida:
│  "Temos 3 opções em Pinheiros! Vou enviar fotos."
├─ Você pode: ✓ Enviar ou ✎ Editar
└─ Se editar, digite sua resposta

Você está no controle (IA é só sugestão).
```

### Passo 3: Conversas Continuadas

```
Cliente replica:
"Qual o preço?"

IA sugere resposta baseada em histórico:
"Tenho opções de R$ 400k até R$ 800k. Qual sua faixa?"

Você aprova → Envia → Cliente responde → Ciclo continua.

IA vai aprendendo o que você fala e melhorando sugestões.
```

### Passo 4: Qualificação Automática

```
Depois de alguns trocas, IA pode sugerir:
"Cliente parece pronto. Você quer enviar nosso
catálogo de imóveis?"

Você clica → Envia catálogo → Cliente vê fotos → Agendá vistoria

IA acelerou tudo. Você só aprovou.
```

## Dicas Para Melhor Desempenho

```
1. Revise respostas sugeridas
   └─ Se não gostar, edite

2. Fale de forma natural no WhatsApp
   └─ IA aprende seu tom

3. Use as sugestões da IA como template
   └─ Personalize quando necessário

4. Quanto mais você usa, melhor fica
   └─ IA aprende padrões
```
