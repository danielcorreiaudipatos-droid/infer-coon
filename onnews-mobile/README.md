# 📰 ONNEWS Mobile App

Read news, earn real money. Available on iOS and Android.

## Features

✅ **News Feed** - Curated articles from 500+ sources  
✅ **Read & Earn** - Get paid to read articles (R$ 0.01-0.35 per read)  
✅ **Engagement Rewards** - Like, comment, share = earn more  
✅ **Reading Streaks** - Bonus multiplier for consecutive days  
✅ **Collections** - Complete challenges for extra rewards  
✅ **Leaderboards** - Compete with other readers  
✅ **Wallet Integration** - Withdraw to bank or PIX  
✅ **Dark Mode** - Easy on the eyes  

## Revenue Potential

- Light user (5 articles/day): R$ 15/month
- Active user (10 articles/day): R$ 40/month
- Heavy user (20+ articles/day): R$ 100+/month

## Getting Started

```bash
npm install
npm start
```

## Technologies

- React Native 0.73
- Expo 50
- TypeScript
- Zustand (state management)
- React Navigation
