CUSTOS VARIÁVEIS/CLIENTE:
├─ API calls (Google): R$ 2-5 por cliente
├─ API calls (Meta): R$ 2-5 por cliente
├─ Gemini requests: R$ 1-2 por cliente
├─ Storage/DB: R$ 0.5 por cliente
└─ TOTAL VAR: R$ 6-13 por cliente/mês

BREAKEVEN:
├─ Free tier: R$ 0 receita
├─ Starter (R$ 299): R$ 292 margem
├─ Pro (R$ 599): R$ 586 margem
├─ Plus (R$ 999): R$ 986 margem

CLIENTES PARA BREAKEVEN:
├─ 100% Starter: 117k / 292 = 401 clientes
├─ 50/50 Starter+Pro: 117k / 439 = 266 clientes
├─ Revenue Share 15%: 117k / 150 avg = 780 clientes

PROJEÇÃO:
├─ 100 clientes: -R$ 58k/mês (Loss)
├─ 300 clientes: +R$ 80k/mês (Profit!)
├─ 1000 clientes: +R$ 280k/mês (Profit++)
├─ 5000 clientes: +R$ 1.4M/mês (Escala)
```

### 7.2 Modelo de Receita

```
RECEITA/MÊS (Projeção 1000 clientes):

Distribution (assumindo):
├─ 30% Free tier: 300 clientes → R$ 0
├─ 40% Starter: 400 clientes × R$ 299 = R$ 119.6k
├─ 20% Pro: 200 clientes × R$ 599 = R$ 119.8k
├─ 10% Plus: 100 clientes × R$ 999 = R$ 99.9k
└─ TOTAL SUBSCRIPTION: R$ 339.3k

Revenue Share (assumindo):
├─ 70% dos clientes geram vendas
├─ Média R$ 5k/vendas por cliente/mês
├─ ADS fica com 15% = R$ 750/cliente
├─ 700 clientes × R$ 750 = R$ 525k/mês
└─ TOTAL REVENUE SHARE: R$ 525k

RECEITA TOTAL: R$ 864k/mês
MARGEM (depois custo): R$ 747k/mês (+86%)
