## 💡 Como Funciona Tecnicamente

### **Fluxo 1: Setup (30 segundos)**

```
1. Varejo: "Quiero vender camisetas"
2. ADS: Cria anúncios (Auto-Ad-Creator)
3. Varejo: "Publica!"
4. ADS: Publica em Google + Meta
5. Varejo: "OK, só pago se vender"
```

### **Fluxo 2: Quando Vende**

```
1. Cliente clica no anúncio
2. Vai para loja do varejo
3. Compra camiseta (R$ 100)
4. Varejo processa pagamento

5. ADS Webhook:
   ├─ Detecta conversão
   ├─ Calcula lucro (R$ 50)
   ├─ Aplica 15% fee (R$ 7,50)
   ├─ Depósita R$ 42,50 para ADS
   └─ Notifica varejo

6. Varejo vê: "Sua venda foi rastreada! ✓"
```

### **Fluxo 3: Pagamento Automático**

```
Diária:
├─ ADS rastreia todas conversões
├─ Calcula 15% do lucro
└─ Depósita na conta do varejo (saldo)

Semanal:
├─ ADS manda relatório
├─ Mostra: Vendas / Lucro / Comissão ADS
└─ Varejo vê exatamente quanto ganhou

Mensal:
├─ Varejo pode sacar o saldo
├─ Ou deixar como crédito para ads
└─ Sem palpite, sem burocracia
```

## 🛡️ Mitigação de Riscos

### **Risco 1: Fraude (Varejo falsifica vendas)**

```
Mitigação:
├─ Pixel rastreia de verdade (não falsa)
├─ Integração com gateway de pagamento
├─ Verificação de IP / Device
├─ Limite de vendas suspeitas = sinalizador
└─ Time manual verifica casos grandes
```

### **Risco 2: Charge-back (Cliente volta)**

```
Mitigação:
├─ ADS não paga comissão até 30 dias pós-venda
├─ Período de charge-back = sem pagamento ADS
├─ Se charge-back, ADS cobra de volta varejo
└─ Protege ambos
```

### **Risco 3: Varejo para de pagar comissão**

```
Mitigação:
├─ Pixel atua automaticamente
├─ ADS deduz comissão do saldo varejo
├─ Se saldo < 0, anúncios pausam
├─ Simples e automático
```

### **Risco 4: Varejo sai antes de pagar**

```
Mitigação:
├─ Contrato: Deve ADS 15% de todas vendas
├─ Mesmo se parar de usar
├─ Pagamento automático do gateway
└─ Protege receita ADS
```
