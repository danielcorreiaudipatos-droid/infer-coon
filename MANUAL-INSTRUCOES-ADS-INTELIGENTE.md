## 📊 Análise & Relatórios

### Visualizar Relatórios

**Menu → Relatórios**

Escolha:
- Campanha específica
- Período (data início → data fim)
- Plataforma (ou todas)

### O que cada métrica significa

```
IMPRESSÕES: Quantas vezes o anúncio foi visto
   └─ Meta: 1.000 impressões = "bom" começo

CLIQUES: Quantas pessoas clicaram
   └─ Taxa esperada: 0.5-2% das impressões

CONVERSÕES: Quantas viraram clientes
   └─ Taxa esperada: 2-5% dos cliques

CUSTO POR CLIQUE (CPC):
   └─ Orçamento / Cliques = CPC
   └─ Exemplo: R$ 100 / 10 cliques = R$ 10/clique

CUSTO POR CONVERSÃO (CPA):
   └─ Orçamento / Conversões = CPA
   └─ Exemplo: R$ 100 / 5 conversões = R$ 20/conversão

ROI (Return on Investment):
   └─ (Receita - Gasto) / Gasto × 100
   └─ Exemplo: (R$ 500 - R$ 100) / R$ 100 × 100 = 400%
```

### Relatório Detalhado

**Exportar em:**
- PDF (para apresentar a clientes)
- Excel (para análise profunda)
- Google Sheets (para colaboração)

## 🆘 Troubleshooting

### Problema: "Campanhas não aparecem"

**Solução:**
1. Verifique se plataforma está conectada
2. Vá para: Configurações → Integrações
3. Desconecte e reconecte a plataforma
4. Atualize a página (F5)

### Problema: "Anúncio não está saindo"

**Checklist:**
- [ ] Orçamento > R$ 0?
- [ ] Data de início já passou?
- [ ] Público-alvo está correto?
- [ ] Imagem/vídeo foi aprovado?
- [ ] Plataforma em "bom funcionamento"?

**Se tudo está OK:**
1. Vá para Campanhas → [Sua Campanha]
2. Clique em "⏸ Pausar"
3. Aguarde 30 minutos
4. Clique em "▶ Ativar"

### Problema: "Métricas estão estranhas"

**Solução:**
1. Verifique período de análise
2. Alguns dados podem ter atraso de 6-12 horas
3. Compare com a plataforma original (Google/Meta)
4. Contate suporte se houver discrepância

### Problema: "Erro ao conectar plataforma"

**Solução:**
1. Verifique se você é o administrador da conta
2. Suas credenciais estão corretas?
3. 2FA está ativado na plataforma? (Desative temporariamente)
4. Tente em outro navegador
5. Limpe cookies do navegador

## 💡 Dicas & Truques

### Como aumentar conversão?

```
1. Teste 3 públicos-alvo diferentes
2. Crie 5+ variações de anúncios
3. Use Auto-Ad Creator para ideias novas
4. Acompanhe métricas diariamente
5. Otimize based on performance
```

### Melhor horário para campanhas?

```
E-commerce: Segunda-sexta, 10h-14h e 18h-22h
B2B: Segunda-quinta, 9h-12h
Varejo: Sexta-domingo, 10h-18h
Serviços: Segunda-sexta, 9h-17h
```

### Como economizar orçamento?

```
1. Comece com público-alvo narrower
2. Use Lookalike Audience (acha pessoas iguais a clientes)
3. Teste em horários de baixa concorrência
4. Ajuste lance bid (preço máximo) baseado em performance
5. Pause públicos que não convertem
```
